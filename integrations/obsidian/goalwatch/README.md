# GoalWatch for Obsidian

This desktop-only companion connects Obsidian to the GoalWatch service on
Omarchy.

## Commands

- **GoalWatch: Use today's daily note** follows the configured Daily Notes path.
- **GoalWatch: Use current file** makes the active Markdown file today's override.
- **GoalWatch: Add goal** inserts the canonical GoalWatch goal block.

Typing `@goal` in a Markdown editor expands to:

```markdown
> Current Goal:
>
> Available Tools: Codex, Browser, Obsidian and any tool useful to the goal.
```

The plugin is installed and enabled by the GoalWatch root `install.sh`.
